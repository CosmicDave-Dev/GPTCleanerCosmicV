CosmicV EdgeCrunch Darkroom V1.4
Windows EXE - Install & Run Guide
=================================

CosmicV EdgeCrunch Darkroom is a portable Windows application created at
Cosmic Dave Studios.

You do NOT need to install Python.
You do NOT need to install OpenCV, NumPy, Pillow, tkinterdnd2, or other
runtime dependencies. Everything required is bundled inside the EXE.

QUICK START
-----------

1. Download CosmicV-EdgeCrunch-Darkroom-V1.4-Windows-x64.zip.
2. Right-click the ZIP and choose "Extract All..."
3. Open the extracted folder.
4. Double-click CosmicV-EdgeCrunch-Darkroom.exe.

NO INSTALLER IS REQUIRED
------------------------

CosmicV EdgeCrunch Darkroom is portable software. Keep the extracted folder
anywhere convenient, such as Desktop, Documents, or another drive.

FIRST LAUNCH
------------

The first launch may take several seconds while Windows and antivirus
software inspect the executable.

WINDOWS SMARTSCREEN
-------------------

The V1.4 executable is unsigned. Windows SmartScreen may warn because the
binary does not yet have established signing reputation.

USING THE PROGRAM
-----------------

1. Click Open Image or drag an image into the application.
2. Choose a Quick cleanup preset or tune the advanced controls.
3. Use the cyan divider to compare Before and After.
4. Mouse-wheel over the image to zoom toward the cursor.
5. Right-drag while zoomed to pan.
6. Use Save As to choose an output path and format.
7. After an output path is chosen, Save writes subsequent changes there.

Supported export formats include PNG, JPEG, WebP, GIF, ICO, BMP, and TIFF.
The Avatar 512 preset creates a centered 512 x 512 image and writes 300 DPI
metadata where the selected format supports it. The Windows Icon preset
creates a multi-resolution ICO.

TARGET MASK
-----------

Target Mask shows the cleanup detector's diagnostic mask over the processed
side. It is a viewing aid only and is not baked into normal image saves.

FULLSCREEN
----------

Press F11 for fullscreen comparison. Press Escape to leave fullscreen.

PRIVACY
-------

CosmicV EdgeCrunch Darkroom processes images locally. The application does
not require an account or cloud upload service to clean images.
